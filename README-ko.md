# 데드라인 플랜트랙 1.0.1 Chrome PWA

이 PWA는 제공된 `일정관리_스케줄러1.html.html` 원본 앱을 그대로 사용하고, Chrome 설치 기능만 추가한 버전입니다.

## 설치

1. HTTPS 주소를 Chrome에서 엽니다.
2. 주소창 오른쪽의 설치 아이콘을 누릅니다.
3. `설치`를 선택합니다.
4. 설치 후 Chrome 탭이 아닌 독립 앱 창으로 실행됩니다.
5. Windows에서 바탕화면 바로가기가 필요하면 Chrome 앱 메뉴에서 `바로가기 만들기`를 선택합니다.

HTML 파일을 직접 더블클릭(`file://`)하면 Chrome 설치 버튼이 나타나지 않습니다. 반드시 HTTPS 주소로 제공해야 합니다.

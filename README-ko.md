# 데드라인 플랜트랙

온라인에서 실행하고 Chrome 앱으로 설치할 수 있는 일정·프로젝트 관리 PWA입니다.

## 온라인 서비스

- 서비스 주소: https://juny0413.github.io/deadline-plantrack/
- GitHub 저장소: https://github.com/juny0413/deadline-plantrack

## Chrome 설치

1. 위 HTTPS 주소를 Chrome에서 엽니다.
2. 주소창 오른쪽의 설치 아이콘을 선택합니다.
3. `설치`를 누릅니다.
4. 설치 후 독립 앱 창에서 실행합니다.

Chrome 메뉴에서 `저장 및 공유 → 페이지를 앱으로 설치`를 선택해도 됩니다.

## 주요 기능

- 간트 차트에서 막대 전체를 드래그해 일정 기간 이동
- 간트 막대 왼쪽 끝 드래그로 시작일 조정
- 간트 막대 오른쪽 끝 드래그로 종료일 조정
- 간트 막대 더블클릭으로 프로젝트·작업 상세 수정
- 작업 수정 화면에서 선행 작업 지정
- 프로젝트 추가·수정 시 선행 프로젝트 지정
- 순환 의존성 방지
- 선행 작업보다 빠른 후행 작업은 간트에 경고 표시
- 간트 변경 내용을 캘린더·하루·주간 타임라인에 즉시 반영
- 집중 모드 시간 1~60분 사용자 설정
- 프로젝트별 마감 임박 알림과 지연 알림
- 프로젝트별 상태 색상 직접 선택
- 서비스워커 자동 업데이트로 일반 재접속 시 최신 버전 반영

## 의존성 사용 방법

1. 작업을 추가한 뒤 작업 목록 또는 간트 막대를 더블클릭합니다.
2. 수정 화면의 `선행 작업`에서 먼저 끝나야 하는 작업을 선택합니다.
3. 저장하면 간트 작업 행에 `선행: 작업명`이 표시됩니다.
4. 후행 작업의 시작일이 선행 작업 종료일보다 빠르면 빨간 테두리와 `순서 확인` 경고가 표시됩니다.

## 저장 안내

현재 일정 데이터는 브라우저 로컬 저장소에 저장됩니다. 같은 브라우저에서는 유지되지만, 다른 기기와 자동 동기화하려면 별도 클라우드 DB와 로그인 연동이 필요합니다.

## 로컬 실행

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

그 다음 브라우저에서 `http://localhost:4173/`을 엽니다. Chrome 설치 기능은 HTTPS 또는 localhost에서 사용할 수 있습니다.
